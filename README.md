# Ddos Telegram By PutraaSiWibu

# Installation
* [`Download Node JS`](https://nodejs.org/en/download/)


## Cloning this repo
```cmd
> git clone https://github.com/PutraWibu/ddos-pler
> cd ddos-pler
```

## Install the package
```cmd
> npm i
```

## Edit config file
Edit the required value in `config.json`. And get bot token at [`@BotFather`](http://t.me/BotFather).
```json
{
    "bot_token": "", // ur token
    "owner": "Putra aja",
    "ownerLink": "https://t.me/PutraTzyh",
    "version": "1.0.0",
    "prefix": "/"
}
```

## Run the bot
```cmd
> npm start
```
